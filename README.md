# Pharmacy Management System

A desktop application built with .NET (C#) to manage core pharmacy operations 
including inventory, prescriptions, and billing.

## Features
- Inventory tracking (stock levels, medicine details)
- Prescription handling
- Bill generation for sales transactions

## Tech Stack
- C#, .NET (Windows Forms)
- SQL Server (via ADO.NET / SqlClient)

## Known Limitations
- Bill generation module has some incomplete edge cases (in progress)

## What I Learned
- CRUD operations and database integration
- Structuring business logic in a layered application
